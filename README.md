# 🌿 Explore Tiss

A responsive web application designed to explore and showcase the rich heritage, scenic beauty, and travel attractions of Tissamaharama.

## ✨ Features
- **Attraction Showcase:** Discover popular cultural and historical sites in Tissamaharama.
- **Interactive UI:** Clean, user-friendly interface optimized for seamless browsing.
- **Responsive Design:** Fully adaptive layout for mobile phones, tablets, and desktops.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** Modern CSS / Responsive Grid
